# DailyDiary

A Django web app: write daily notes in a notepad UI, see them on a monthly calendar + 24-hour day view, and ask an AI to summarize any day. Built sequentially as a learning project.

See [`PROJECT_ROADMAP.md`](PROJECT_ROADMAP.md), [`PROGRESS_TRACKER.md`](PROGRESS_TRACKER.md), and [`SYSTEM_DESIGN.md`](SYSTEM_DESIGN.md).
